# Jules_projects

## Comma-Separating Tool

This tool is a simple web-based utility that converts a list of words (separated by spaces, tabs, or newlines) into a single string with each word separated by a comma and a space.

### How to Use

1.  **Open the Tool:**
    *   Download the files (`index.html`, `style.css`, and `script.js`).
    *   Open the `index.html` file in your preferred web browser.

2.  **Operate the Tool:**
    *   Enter your text (words separated by spaces, tabs, or new lines) into the top input area labeled "Enter text here...".
    *   Click the "Separate" button.
    *   The comma-separated version of your text will appear in the bottom (read-only) text area labeled "Result...".
    *   If you input an empty string or only whitespace, the result will be an empty string.
